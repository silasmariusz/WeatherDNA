## 2. Stevenson Screen Topology (MUX 0x72)

This section describes the layout of environmental sensors, which are housed within a Stevenson Screen to ensure accurate meteorological measurements. All sensors are connected to the main I2C bus via a TCA9548A I2C multiplexer (MUX) operating at I2C address `0x72`.

The multiplexer is critical for this design as it allows the MCU to communicate with multiple I2C devices that share the same address. The firmware must first select a channel on the multiplexer before communicating with the sensor(s) on that channel.

| Channel | Sensor(s)           | I2C Address(es) | Primary Measurements                                         |
| :------ | :------------------ | :-------------- | :----------------------------------------------------------- |
| **CH0** | BME688 AI           | `0x77`          | Temperature, Humidity, Barometric Pressure, Gas (VOCs) with AI |
| **CH1** | ZMOD4510            | `0x33`          | Outdoor Air Quality (OAQ), Ozone (O₃) Index                  |
| **CH2** | SCD41 + SGP41       | `0x62` + `0x59` | CO₂, Temp, Humidity (SCD41) & VOC, NOx Index (SGP41)         |
| **CH3** | BMV080              | `0x57`          | Particulate Matter (PM1.0, PM2.5, PM10)                      |
| **CH4** | BME690              | `0x77`          | Temperature, Humidity, Barometric Pressure, Gas (VOCs)       |
| **CH5** | SHT45               | `0x44`          | High-Accuracy Temperature & Humidity                         |
| **CH6** | ILPS22QS            | `0x5C`          | High-Accuracy Absolute Pressure (Barometer)                  |
| **CH7** | BMP585              | `0x46`          | High-Accuracy Absolute Pressure & Temperature                |

**Usage Note on I2C Address Conflicts:**
The BME688 (on Channel 0) and BME690 (on Channel 4) sensors both use the default I2C address `0x77`. The I2C multiplexer is essential to prevent an address collision on the bus. To read from the BME688, the firmware must first write to the multiplexer (`0x72`) to enable Channel 0, and then it can communicate with address `0x77`. The same process applies to the BME690 on Channel 4.
